# /start/connect

To play Dealers.sh you need a wallet that can sign transactions on the Abstract blockchain. You do not need to download a separate app or create an account on a website. The game lives inside the NFT itself, and your wallet is the only login.

There are two common ways to connect, and either works equally well.

## Option 1. Abstract Global Wallet

Abstract Global Wallet (AGW) is the simplest path for most players. You sign in with an email address or a social account, and AGW manages the cryptographic side for you. There is no seed phrase to write down and no extension to install. Once you have an AGW set up and funded with a small amount of ETH on Abstract, you can hit "Connect" inside the NFT viewer and start playing right away.

You can create an Abstract Global Wallet at [abs.xyz](https://abs.xyz).

## Option 2. An injected wallet

If you already use a browser-extension wallet like MetaMask, Rabby, or Frame, you can use that instead. Make sure the wallet has the Abstract network configured, then open your Dealers.sh NFT in any viewer that supports `animation_url`, hit "Connect," and approve the signature request.

## Where the game actually runs

The game is embedded inside the NFT itself, which means you play it by opening your dealer in any tool that renders animated NFTs. The most common places are the Abstract block explorer, Magic Eden's Abstract marketplace, and any other interface that respects the `animation_url` metadata field. You do not need to visit a separate website to play.

If you do not own a dealer yet, you can mint one at [dealers.sh](https://dealers.sh). Once you have one in your wallet, return here and follow [/start/your-dealer](/start/your-dealer).
