# /the-art/dynamic

The NFT is not a static picture. It has state. The state shows up.

## What changes

- **The UI inside the NFT.** Your stats, area, inventory, action log. All live state read from the chain.
- **Achievement visuals.** Some claimed achievements add visual elements to the character: a chain, a hat, a wound, a smirk.
- **Mood / status overlays.** Heat, jail, safe-house all change the visual context behind the UI.

## What does not change

The base traits rolled at mint are permanent. The character you minted is the character you have. You can decorate them. You can't replace them.

Your dealer levels up. Your JPEG doesn't.
