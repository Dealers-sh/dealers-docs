# /the-art/dynamic

A Dealers.sh NFT is not a static image. The base traits are assigned at mint and never change, but a layer of game state lives on top of those traits and updates continuously as you play. This page explains which parts move and which parts do not.

## What changes as you play

The most obvious dynamic element is the game UI that renders inside the NFT. Stats like reputation, heat, cash, attempts, and stash are all read from on-chain state at render time, which means they reflect whatever just happened in your most recent transaction. The action log, the area you are in, and any pending notifications also live in this updating layer.

Everything that moves lives in that game UI overlay or in the token metadata. The underlying character art does not change as you play. Your area, jail status, most recent PVP outcome, and active heat level all update from on-chain state as soon as a transaction confirms, but they surface through the game UI and the live metadata traits below, not through any edit to the artwork itself.

## Dynamic traits in the NFT metadata

The standard `tokenURI` for a Dealers.sh NFT carries four **live** traits in addition to the fixed visual attributes. Each one is read from the contract at query time, so when a marketplace or wallet refreshes the token, the value reflects the dealer's current on-chain state.

| Trait | Source | Notes |
| --- | --- | --- |
| `Rank` | `getReputationTitle(totalReputation)` | The current tier name, drawn from the 10-tier ladder — Outsider → Legend. See [/progression/ranks](/progression/ranks). |
| `Infamy` | `getInfamy(tokenId)` | Numeric, increments and decrements with PVP outcomes. |
| `Area` | current area's name | The street, Safe House, Black Market, or Jail. |
| `Heat` | star string | Rendered as `⭐` repeated to match the heat level. |

The trait names and order match `DealersNFT._getDynamicTraits`. Marketplaces that index ERC-721 metadata pick these up automatically, which means a filtering UI can list dealers by rank or infamy without any off-chain indexer.

## What stays fixed

The base traits rolled at mint are permanent. The character you minted is the character you keep. There is no mechanism in the game to reroll or swap out anything that was set at mint, and the rendered character art stays the same from mint onward.

The summary line we use to capture this is that your dealer levels up while your JPEG stays put. The game UI and the live metadata move, the artwork does not, and both are by design.
