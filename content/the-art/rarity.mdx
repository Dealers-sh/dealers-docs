# /the-art/rarity

The trait table.

## What gets randomized

Each dealer is rolled at mint across several trait categories:

- **Background**
- **Body / character base**
- **Hair**
- **Eyes**
- **Mouth**
- **Outfit**
- **Accessory**

## Distribution

Each trait category has tiers from common to rare. Rarer traits appear in fewer dealers. The numbers are fixed at mint and cannot be re-rolled.

A rare look is a flex. It is not a gameplay edge. A common dealer with high REP outranks a 1/1 with a clean record.

## Reading on-chain

Trait data is queryable on the NFT contract. Anyone can pull the assignment for any token. No metadata API in the middle.
